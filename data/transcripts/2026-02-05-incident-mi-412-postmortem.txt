[00:02:32] Daniel Okoye: For the record, I did run it on the replica first. The replica has the same specs but no production read traffic, so the cache eviction didn't show up there. That's my mistake — I tested the disk impact and not the cache impact.

[00:03:29] Marcus Webb: No objection. I'd like the replica before you take away primary access, though, not after.
[00:03:37] Tom Nakamura: Fair. Replica first, then revoke.
[00:03:42] Tom Nakamura: Second. In the architecture review on the fifteenth we decided to enable pgvector on the existing RDS instance for the H2 natural-language prototype. I want to reverse that decision.
[00:03:58] Daniel Okoye: I expected this, and I'm not going to fight it. Go ahead and make the case.
[00:04:05] Tom Nakamura: The case is that Tuesday was a two-hour customer-facing latency incident caused by an analytics workload sharing a buffer cache with the transactional path. An embedding index is exactly that same shape of workload: large sequential reads over data nobody in the checkout path cares about. We would be setting up the same incident deliberately, having just written the postmortem for it.
[00:04:35] Marcus Webb: I raised this in January and I said I wouldn't die on the hill. I'd like it noted that I'm now willing to die on the hill.

[00:04:49] Daniel Okoye: My original argument was that a prototype shouldn't require new infrastructure. That argument was about cost of setup, and it assumed the prototype was harmless. Tuesday shows it isn't harmless on that instance. So the argument doesn't hold and I withdraw it.
